# 训练规则与计分口径

六个模块统一产出 `GameOutcome`，由 `TrainPlayView` 组装为 `TrainingRecord`。
**所有模块的 `score` = 所产出维度分的平均值（四舍五入，0~100）**，避免各模块各写一套总分逻辑。

通用公式（`src/training/engines.ts`）：

```
速度分   = ratio ≤ 1 ? 100 : clamp(100 - (ratio - 1) × 55, 0, 100)，ratio = 平均反应时 / 参照时
综合分   = 正确率 × 0.75 + 速度分 × 0.25
正确率%  = round(答对 / 总题量 × 100)
```

参照时（`targetMs`）按模块难度设定，见各模块。

## 训练小馆分类（孩子端展示）

只影响孩子端「训练小馆」的分区展示，不改六维评估、积分、每日上限与徽章判定。

| 分类 | 模块 | 一句话 |
| --- | --- | --- |
| 🎯 专注力训练 | 色词大挑战、抗干扰捕捉、多线索追踪 | 坐得住、看得准、不被带跑 |
| 🧠 记忆力训练 | N-Back 双任务 | 边看边记，记住再动手 |
| 🔀 反应力训练 | 分类切换 | 规则一变，马上跟上 |
| 🧮 逻辑思维训练 | 加减乘除速算、AI 数学应用题 | 算一算、想一想，脑子转起来 |
| 🍅 作业工具 | 作业番茄钟 | 单独一区，不是训练游戏，不计入每日上限 |

- 分类写在 `shared/constants.ts` 的 `TRAINING_CATEGORIES` 与 `MODULES[].category`（静态常量，不落库、不涉及 `SCHEMA_VERSION`）。
- 一个模块只归一类；模块本身仍按 2 个注意力维度计分，家长端六维雷达不变。
- `logic`（逻辑思维）类目由「加减乘除速算」（0.14.0 起）与「AI 数学应用题」（0.15.0 起）启用。

## ① 作业番茄钟 🍅（pomodoro）

**训练维度**：持续注意力、冲动抑制
**是否计入每日训练上限**：**否**（`countsTowardDailyLimit: false`）

流程：

1. 填写作业名称；列出一份作业清单（每项可单独勾选完成），可手动添加，也可用 AI 列 3~6 项（失败时回退到本地示例）；**至少列 1 项才能开始**
   - 家长可以提前在「家长中心 → 作业」录入当天清单，孩子进入作业页会自动带出，也可以点「不用这份，我自己列」
   - 家长留的清单项带「家长」标记：孩子可以追加自己的任务，但**不能删除家长项**；家长端能看到孩子额外加了哪些
2. 可选的大脑热身 60 秒（默认开启，可取消）：呼吸 → 手指操 → 说出 3 件事，也可随时跳过
3. 专注计时：20 / 25 / 30 分钟预设，或自定义 5~60 分钟；支持暂停、提前结束；清单常驻，可随手勾选但**不能再增删或改标题**
4. 专注结束进入 **4 项自检**：任务完成 / 不会的已标记 / 桌面收拾 / 远眺休息
5. 自检全勾选后可「完成作业」或「休息 5 分钟后继续下一轮」
6. 判定在**专注倒计时归零（或点「提前结束这一轮」）那一刻**冻结：自检页的清单只读，不能再勾；多轮作业以最后一次结算时的总清单为准
7. 完成后保存 `HomeworkSession`；服务端为已完成会话自动生成一条番茄钟训练记录（见下）

**清单锁定**：

- 点「开始」（进入热身或专注）时清单即锁定，之后只能勾选 `done`，不能增删项、不能改标题；界面上不再显示「添加 / 删除」按钮，服务端也会忽略这类改动。
- 服务端权威：`POST /api/state/homework` 对已存在的会话只接受 `items[].done` / `doneAt` 变化，其余以首次落库的清单为准；因此没法靠中途删项把「负」变成「正」。
- 会话结算（`status = done`）后清单连勾选也冻结，`verdict` 一旦落库不会再被后续提交改写。
- 清单至少 1 项才能开始；没有清单的会话不会产生（空清单会被视为全部完成，所以入口直接拦住）。
- 家长计划与会话是两份数据：点「开始」时把计划清单复制到会话并写入 `planId`；之后家长再改或删计划，都不会影响正在写或已完成的会话。

**家长预录清单**：

- 家长按「孩子 + 日期」录入，日期允许今天前后 7 天（老师发的通知可能含前几天作业）；同一天可录多个科目（按 `subject` 分组，`subject` 为空保持「一天一份」旧行为），同一科目可反复修改，孩子还没开始就按最新版本带出。
- 家长可粘贴老师发的整段作业通知，用 AI（`POST /api/ai/homework-parse`）一键解析成多份科目计划；未配置或失败时用本地规则 `src/utils/homeworkParse.ts` 按科目标题拆分，解析后逐科确认保存。
- 孩子只在进入作业页时拉取一次快照；家长刚留的清单会在下次进入作业页时出现，不需要手动清缓存。当天有多份时，孩子端把多科合并成一份清单，按科目分小节展示，统一进度与判定。
- 运行中的会话不受计划修改影响；如果家长改错了，孩子按已开始的清单完成即可，下一轮重新开始时才会用新清单。
- 计划本身不产生积分或徽章；判定仍只看会话复制过去的清单。解析出的「温馨提示 / 家长须知」会作为清单项（💡 图标），与其他项一样计入正/负判定。

**首页作业提醒**：

- 孩子端首页在 hero 下方固定位置显示作业提醒卡，底栏「作业」tab 显示当天作业的科目数角标；两者随作业完成自动消失。
- 判定纯派生、不落库：当天有家长计划且存在未完成项就提醒（未开始 / 进行中 / 部分完成都提醒），全部完成才消失。
- 完成度按「当前计划项 id 是否已被今天「进行中 / 已完成」的会话勾选过」计算；放弃的尝试、超过 2 小时没动作的进行中会话都不计入。家长新增或改项后旧会话没覆盖新项，提醒会自动重新出现。
- 卡片按状态变文案（「家长给你留了今天的作业」/「今天的作业还没做完：已完成 X/Y 项」），列出各科目进度与剩余科目；带「🔊 听一下」按需语音，不自动播报。
- 每次进入首页都会拉一次快照，家长刚留/改过的作业能立刻提醒；离线时继续用本地缓存。

**低年级可读性（1~2 年级识字量有限）**：

- 每项按标题自动配科目图标（📐数学 📖语文 🔤英语 🎨美术 🎵音乐 🏃体育 🧪科学 📌其他），家长可在录入时从固定科目组改。
- 每项带「🔊」逐项朗读，清单顶部「🔊 读全部」连读；训练游戏「怎么玩」旁「🔊 读规则」。用系统语音，无需后端。
- 朗读作业时先报所属科目与该科内序号（如「语文作业，一：学习园地四，指读课本56页、57页拼音」）；「读全部」按科目分段（如「语文：A、B。数学：C、D。」）；没有科目的项报「作业」前缀。孩子先听到科目再听到任务，更容易听懂。
- 清单项与训练规则字号加大；勾选整行可点，减少「看不清、点不中」。
- 孩子手动加的清单项同样自动识别科目图标。

**正/负判定**：

- **正**：清单全部完成（没有清单时视为完成，界面已不允许这种会话）
- **负**：还有任意一项没完成
- 整个会话判一次：第 1 轮没做完、休息后第 2 轮做完，最终仍算「正」
- 提前结束且还有未完成项 → 先二次确认，确认后记为「负」
- 暂停与切页面不计时（当前策略），不会因为离开被判负

**离开与恢复**：

- 切到首页/训练/成长等页面时，番茄钟自动暂停并把剩余秒数、轮次、清单、自检状态写入本地草稿；底栏「作业」显示进行中小圆点。
- 回到作业页展示「已回到上次的进度」，点「继续」才继续倒计时；刷新、关标签页同样能恢复。
- 进行中的会话同步到服务端（开始/暂停/勾选节流 5 秒/离开/完成），家长端可看到「正在写作业」。
- 超过 2 小时没有动作的进行中会话自动作废，下次进入作业页提示重新开始（作废不判定、不写记录）。
- 训练小游戏中途离开会弹窗确认「本次成绩会作废」，不做中途续玩。

**记录与积分**：客户端只写 `HomeworkSession`；服务端在会话变为 `done` 时自动生成/更新一条 `TrainingRecord`（`id = rec_hw_<会话id>`，`module = pomodoro`），避免离线重放重复加分。客户端不得直接上报 `module: pomodoro` 的记录，服务端会丢弃。

| 字段 | 取值 |
| --- | --- |
| `passed` | 正 `true` / 负 `false` |
| `score` | 正 **80~100**：`80 + 20 × (1 - 实际专注 / 计划专注)`；负 **40~70**：`40 + 30 × 清单完成率` |
| `accuracy` | 清单完成率；没有清单时记 1 |
| `dimensionScores` | `sustained` 与 `inhibition` 都等于 `score`（负记录同样计入雷达） |
| `durationSec` | 各轮 `endedAt - startedAt` 之和，取不到时退回会话总时长 |
| `totalTrials` / `correctTrials` | 清单总项数 / 已完成项数（没有清单时都为 1） |
| `errors` | 固定 `[]` |
| `difficulty` | `1` |

积分：正 **20** 分、负 **10** 分，通过这条番茄钟记录计入，不再单独按会话累加。番茄钟记录不计入每日训练分钟。

## ② 色词大挑战 🌈（stroop）

**训练维度**：选择性注意力、冲动抑制
**题量**：24 题；**难度**：1

刺激：显示一个表示颜色的汉字（红/黄/蓝/绿），墨色与字义可能冲突（**冲突 75%**，一致 25%）。
作答：点击“文字真正的颜色”。反应时从刺激出现到点击。

计分：

```
selective = 综合分(总正确率, 平均反应时, 950ms)
inhibition = 综合分(一致题正确率, 平均反应时, 1100ms)
score = round((selective + inhibition) / 2)
```

错误类型：`颜色点错`（答错数）、`反应超时`（RT > 3s 的题数）。

**设计意图**：冲突条件下仍能按规则作答，反映抑制优势反应的能力；一致题用于对照。

## ③ 抗干扰捕捉 🔍（capture）

**训练维度**：选择性注意力、持续注意力
**时长**：40 秒；**难度**：1

规则：顶部显示目标组合（如「蓝色三角形」），图形约每 950ms 出现一个，存活 1.25s；点击目标得分，误点干扰项记错误，目标消失未点记漏。

```
命中率   = 命中 / (命中 + 漏掉)
动作正确率 = 命中 / (命中 + 漏掉 + 误点)
selective  = 动作正确率 × 60% + 命中率 × 40%
sustained  = 综合分(命中率, 平均命中反应时, 900ms)
```

错误类型：`漏掉目标`、`误点干扰项`。
平均反应时只统计命中目标的点击。

## ④ N-Back 双任务 🧩（nback）

**训练维度**：工作记忆、分配注意力
**题量**：22 个刺激（前 2 个为基线）；**N = 2**；`difficulty = 2`

刺激：九宫格中一个彩色圆点，显示 1.0s，间隔 0.62s。
作答：位置与 2 个之前相同 → 点「位置一样」；颜色相同 → 点「颜色一样」；都不相同 → 不点。两个维度可同时按。

逐维度统计命中 / 漏报 / 误报 / 正确拒绝：

```
维度正确率 = (命中 + 正确拒绝) / (命中 + 漏报 + 误报 + 正确拒绝)
overall    = (位置正确率 + 颜色正确率) / 2
workingMemory = 综合分(overall, 平均反应时, 1300ms)
divided       = 综合分(min(位置正确率, 颜色正确率), 平均反应时, 1400ms)
```

错误类型：`位置漏报`、`位置误报`、`颜色漏报`、`颜色误报`。
**设计意图**：`divided` 取两维度较低者，避免“只盯一个维度”拿高分。

## ⑤ 分类切换 🔀（switch）

**训练维度**：转换注意力、冲动抑制
**题量**：24 题；每 4 题切换一次规则；**难度**：1

规则 A（奇偶）：判断卡片数字是奇数还是偶数。
规则 B（颜色）：判断卡片背景是红色还是蓝色。
顶部明显展示当前规则，切换时闪烁提示。

```
切换代价 = max(0, 平均切换题反应时 - 平均重复题反应时)
切换惩罚 = clamp(切换代价 / 1200, 0, 1)
switching = clamp(正确率 × 0.7 + (1 - 切换惩罚) × 30, 0, 100)
inhibition = 综合分(正确率, 平均反应时, 1000ms)
```

错误类型：`规则用错`、`切换变慢`（切换代价 > 700ms 记 1 次）。
`extra.switchCostMs` 记录切换代价，供后续分析使用。

## ⑥ 多线索追踪 🎯（tracking）

**训练维度**：分配注意力、持续注意力
**难度**：1

两阶段：

1. **视觉追踪**：6 个球中 2 个先标橙 2.2s，随后变蓝并移动 6.4s，停下后 7s 内点击记住的 2 个球。
2. **听觉回忆**：语音播报 4 个数字（0.8 倍速），用数字键盘按顺序输入；可再听一次；不支持语音时数字短暂显示在屏幕上。

```
trackScore = 点对的目标数（0~2）
audioScore = 数字位置正确的个数（0~4）
trackAcc = trackScore / 2
audioAcc = audioScore / 4
divided   = clamp(round(trackAcc × 45 + audioAcc × 45 + 10), 0, 100)
sustained = clamp(round(trackAcc × 70 + (点击过 ? 30 : 0)), 0, 100)
accuracy  = (trackAcc × 0.5 + audioAcc × 0.5)
```

错误类型：`追踪认错球`（2 - trackScore）、`数字记错`（4 - audioScore）。
平均反应时记为 0（本模块不统计反应时）。

## ⑦ 加减乘除速算 🧮（arithmetic）

**训练维度**：工作记忆、冲动抑制
**是否计入每日训练上限**：是（`countsTowardDailyLimit: true`，约 3 分钟）
**题量**：20 题

**难度档**（家长在档案里设默认，孩子每次进入可临时切换；训练记录保存本次实际难度）：

| 难度 | 题型 | 说明 |
| --- | --- | --- |
| 1 | 20 以内加减法 | 只加只减，和 / 差不超 20 |
| 2 | 100 以内加减法 + 九九乘法 | 两位数加减（约 70%）与乘法口诀（约 30%） |
| 3 | 混合四则 | 先乘除后加减，含括号：`(a±b)×c`、`a+b×c` 型 |

**作答方式**（家长在档案里按孩子设置，缺省 `choice` 选项四选一）：

- `choice`：每题给 4 个答案（正确答案 ± 小偏移；难度 3 额外加入「运算顺序搞错」的干扰项，有教学意义），点一个即可。
- `keypad`：0-9 数字键盘 + 退格 + 确定，自己输入答案，更接近口算练习。

**计分**（复用 `engines.ts` 的 `compositeScore`，正确率 75% + 速度 25%）：

```
workingMemory = compositeScore(正确率, 平均反应时, 2500ms)
inhibition    = compositeScore(正确率, 平均反应时, 3000ms)
score         = (workingMemory + inhibition) / 2
```

- 心算要记住中间结果 → 工作记忆；忍住不抢答、不靠猜 → 冲动抑制。
- 错误类型：`算错`、`反应超时`（单题超过 5000ms）。

## ⑧ AI 数学应用题 📖（storymath）

**训练维度**：工作记忆、冲动抑制
**是否计入每日训练上限**：是（`countsTowardDailyLimit: true`，约 10 分钟）
**题量**：主轮与专项轮均 5 题（AI 生成，一次返回）

**年级档**（家长在档案里设默认，孩子每次进入可临时切换；训练记录保存本次实际年级）：

| 年级 | 知识范围 |
| --- | --- |
| 1 | 20 以内加减、比大小 |
| 2 | 表内乘除、100 以内加减 |
| 3 | 三位数加减、乘除法、时分秒 |
| 4 | 多位数乘除、运算律、小数初步 |
| 5 | 小数四则、简易方程、分数 |
| 6 | 分数/百分数、比例、圆 |

**AI 依赖**：题目由大模型生成（`POST /api/ai/storymath`），每题带**知识点标签**（`knowledgePoint`）。**未配置 AI 时该模块在训练小馆里禁用**，孩子点进去看到「请家长先配置 AI」提示；配置好即可用。题目强制为 JSON 数组 `[{ text, answer, unit, knowledgePoint, hint? }]`，服务端解析失败或答案非数字时跳过该题并重试补足，仍不足返回 `AI_PARSE_ERROR`。

**流程**（0.16.0 重做）：

1. **出题**：AI 出 5 题，每题标注知识点（供专项训练引用）。
2. **答题**：每题**二选一**——`直接给答案`（键盘输入，支持负数、两位小数）或 `列式拍照`（孩子把竖式/计算过程拍下来，`POST /ai/storymath/recognize` 让视觉模型提取答案，**先回显让孩子确认或修正**再进判卷；`confidence < 0.5` 提示核对）。题面旁有「🔊 读题」按钮，用朗读链路（原生 → Edge → OpenAI）帮识字量有限的孩子听题。
3. **判卷**：全部答完后一次性 `POST /ai/storymath/judge`，AI 逐题判定对错，返回标准答案、**错误位置**（`errorStep`）、**分步解题思路**（`solution`）。拍照题若列式过程有错但最终答案碰巧对，也判错并写明错在过程。
4. **结果页**：正确率 + 逐题讲解（可展开看错因与思路）。
5. **专项训练**：有错题时可点「专项训练」，按**错题知识点**（去重）出变式题（`focusPoints`），最多累计 **2 轮**；仍错可再来一轮，达到上限提示休息。专项轮题目带 `round: 'remedial'` 标记。

**计分**（复用 `engines.ts` 的 `compositeScore`，正确率 75% + 速度 25%）；应用题需更长理解时间，参照时放宽：

```
workingMemory = compositeScore(正确率, 平均反应时, 4000ms)
inhibition    = compositeScore(正确率, 平均反应时, 5000ms)
score         = (workingMemory + inhibition) / 2
```

- **计分口径**：**主轮成绩计入本次训练**（正确率 / 反应时），专项训练轮是巩固、不稀释主轮正确率；`workingMemory` / `inhibition` 映射不变（六维雷达与徽章不受影响）。
- 读懂题意、分步列式 → 工作记忆；不抢答、认真读题 → 冲动抑制。
- 错误类型：`算错`（以 AI 判卷为准）、`反应超时`（单题超过 8000ms）。
- 逐题明细持久化到训练记录 `storymathDetail`（主轮 + 专项轮，含提交值 / 标准答案 / 对错 / 错因 / 思路 / 知识点 / 作答方式），供家长端回看。

## 计分与展示约定

- 记录页展示的「综合分」即 `record.score`
- 雷达图与徽章判定统一使用最近 **10** 条记录（`DIMENSION_WINDOW`）中各维度得分的平均（`dimensionAverages`）
- 家长端 AI 摘要只发送最近 10 条记录的聚合值，不发送原始明细
- 徽章阈值以 `shared/constants.ts` 为准（维度达到 75 分、次数里程碑等）

## 变更流程

调整题量、参照时或权重时：
